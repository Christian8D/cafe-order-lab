# Café Order Lab

Students run the café register in the browser. The left side is the program. The right side is the Python it is running. Each drink and the sandwich start with 10 in stock.

Python runs on the student's own computer with Pyodide. Orders are not sent to a server.

```bash
npm install
npm run dev
```

Open the local address Next prints. Press Run if the register does not start on its own.
